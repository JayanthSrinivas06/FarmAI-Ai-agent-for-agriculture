# 🌾 RakiCrops AI – Intelligent Crop Advisor

An AI-powered web application that recommends crops based on environmental and soil parameters using a trained **Random Forest ML model**, and then generates a complete **agriculture plan, timeline, and market price forecast** using the **Google Gemini AI** agent.

> Built for farmers in **Andhra Pradesh & Telangana**, India.

---

## ✨ Features

- 🤖 **ML Crop Prediction** — Top-5 crop recommendations using a trained Random Forest model (12 input parameters)
- 📋 **AI Farming Plan** — Full step-by-step agriculture guide generated by Gemini AI
- 📅 **Month-by-Month Timeline** — Season-aware farming schedule
- 💰 **Market Price Forecast** — Estimated selling price per KG after harvest
- ⚡ **FastAPI Backend** — Clean, modular REST API with auto-generated docs at `/docs`
- 🎨 **Modern Frontend** — Dark agri-tech UI with glassmorphism and animations

## ⚙️ Setup & Run Guide

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Raki_crops.git
cd Raki_crops
```

### 2. Create & Activate Virtual Environment

```bash
# Create venv
python -m venv .venv

# Activate — Windows
.venv\Scripts\activate

# Activate — Mac/Linux
source .venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Download the Trained Model ⚠️

The model file (`model/best_model.pkl`) is **not included in the repository** due to its large size (~1.1 GB).

- Download `best_model.pkl` from the shared link (ask the project owner)
- Place it at: `model/best_model.pkl`

```
Raki_crops/
└── model/
    └── best_model.pkl   ← place here
```

### 5. Set Up Your Gemini API Key ⚠️

The `.env` file is **not included in the repository**. Create one from the template:

```bash
# Windows
copy .env.example .env

# Mac/Linux
cp .env.example .env
```

Then open `.env` and add your key:

```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
```

> Get a free API key at: https://aistudio.google.com/app/apikey

### 6. Prepare Training Data (optional — for retraining only)

CSV dataset files are **not included in git**. They were originally downloaded via `gdown` from Google Drive in `model_training/train.ipynb`. If you want to retrain:
- Manually download the CSV files and place them in `model_training/`
- Run the notebook cells (skip the `gdown` cell if you have the files locally)

```
http://localhost:8000

```

## 🌐 API Endpoints

| Method | Endpoint             | Description                          |
|--------|----------------------|--------------------------------------|
| GET    | `/api/districts`     | List all valid districts             |
| POST   | `/api/predict`       | Predict top-5 crops from field data  |
| POST   | `/api/farming-plan`  | Generate Gemini AI agriculture plan  |

### Example `/api/predict` Request Body

```json
{
  "district": "Krishna",
  "season": "Kharif",
  "year": 2024,
  "NDVI_mean": 0.39,
  "elevation": 255,
  "evapotranspiration": 0.05,
  "rain": 530,
  "slope": 0.65,
  "soil_carbon": 23,
  "soil_ph": 6.5,
  "soil_texture": 3,
  "temp": 26
}
```

## 🛠️ Model Information

| Parameter        | Value                          |
|------------------|--------------------------------|
| Algorithm        | Random Forest Classifier       |
| Input features   | 12 (NDVI, elevation, rain, etc)|
| Top-1 Accuracy   | ~25.7%                         |
| Top-3 Accuracy   | ~64.6%                         |
| Top-5 Accuracy   | ~96.9%                         |
| Output           | Crop recommendation + probs    |

> **Note:** Top-1 accuracy appears low because there are 30 possible crop classes. Top-3 and Top-5 accuracy are much higher and are the recommended evaluation metrics for this use case.
